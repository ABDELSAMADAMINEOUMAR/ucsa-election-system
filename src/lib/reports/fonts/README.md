Noto Sans Regular/Bold and Noto Sans Arabic Regular are unmodified font assets
from https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf (retrieved
7 November 2026). OFL.txt contains their SIL Open Font License 1.1.

These fonts support PDF report text and do not replace or modify the UCSA logo.
PDF generation embeds subsets; unsupported characters are displayed as explicit
Unicode code point notation. Complex bidirectional text requires human review.
